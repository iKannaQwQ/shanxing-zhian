## 4. 跨浏览器重点

| 浏览器 | 重点看 |
|---|---|
| iOS Safari | 地址栏遮挡底部内容、`position: fixed` 表现、图片长按菜单 |
| Android Chrome | 表格横向滚动、抽屉菜单 |
| Windows Edge / Chrome | 中文字体渲染、表格列宽、缩放 125%/150% 下是否错位 |
| Windows Firefox | `image-rendering: pixelated` 是否生效（深度图会糊但不影响判断） |

**已知风险（我无法在代码层排除）**：

1. **画布合成**：实时监控页用 `globalCompositeOperation = 'source-in'` 给掩码着色，
   Safari 上表现需要实测。
2. **深度图解析**：`Float32Array` 直接解析二进制，字节序在小端设备上一致，
   但个别浏览器对 `arrayBuffer()` 的兼容性要确认。
3. **大表格**：Element Plus 在窄屏下的横向滚动条可能被裁切。
4. **字体**：`PingFang SC` 在 Windows 上不存在，会回退到 `Microsoft YaHei`，
   行高可能略有差异。
